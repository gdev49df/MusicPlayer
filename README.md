# Припев

Программа для Windows: из вашей песни делает видео для TikTok с обложкой и синхронным текстом.

**Скачать:** [Pripev-Setup.exe](https://github.com/gdev49df/MusicPlayer/releases/latest/download/Pripev-Setup.exe) — запустите, программа установится сама и появится на рабочем столе.

Программа не подписана, поэтому при первом запуске Windows может показать окно SmartScreen:
«Подробнее» → «Выполнить в любом случае».

## Обновления

Вверху окна: «Проверить обновления» → «Обновить». Программа скачает новую версию, установит её и перезапустится.

Каждый пуш в `main` (кроме правок только в `.md`, `server/` и `player/`) собирает новую версию `1.0.N` и выкладывает её в Releases.

## Возможности

Окно разделено на вкладки: «Трек», «Текст», «Вид», «Звук», «Проект».

**Трек.** Своя музыка (MP3, M4A, WAV, FLAC). Обложка альбома и фото артиста находятся по названию, можно поставить свою картинку, а на верхнюю карточку — своё фото или видео.

**Текст.** Переключатель «Автоматически» / «Свой текст», оба варианта хранятся отдельно.

- автоматически: текст с таймингами ищется в базе; для slowed и sped up версий тайминги растягиваются под длину файла
- свой текст: напишите или вставьте, откройте `.lrc` или скопируйте найденный
- построчный редактор: время, текст, добавить, удалить, «взять текущее время»
- отмена и возврат: кнопки ↶ ↷ или Ctrl+Z и Ctrl+Shift+Z
- цветные слова выбираются нажатием, слово под кругом задаётся для каждой строки
- разметка в такт пробелом
- синхронность: «Текст раньше» / «Позже», «Поётся сейчас» у строки, растяжение таймингов, скорость заливки слов

**Вид.** Панель 16:9 и 9:16, «Плеер», «Большая обложка», «Крупный текст», «Переписка», «Экран блокировки», «Пластинка», «Кассета».

- «Переписка»: строки песни приходят сообщениями, видно «печатает…», есть звук сообщения
- «Экран блокировки»: часы, плеер, строки песни и свои сообщения уведомлениями
- появление текста: прокрутка строк, слова по одному, печатная машинка, одно крупное слово
- девять шрифтов с казахскими буквами; у каждой строки можно выбрать свой цвет и шрифт

- эффекты на верхней карточке: дождь, снег, искры, VHS, глитч; реакция на бит; настоящий эквалайзер
- готовые темы и свои пресеты
- плавное появление блоков, бегущая строка для длинных названий
- все надписи меняются, лишние блоки скрываются, всплывающие сообщения (`0:08 Имя: текст`)

**Звук.** Громкость, плавное начало и конец, slowed, reverb, усиление баса. Затухания слышно при прослушивании кнопкой «▶ Фрагмент».

**Проект.** Всё сохраняется само и возвращается после перезапуска и обновления. Проект можно записать в файл `.pripev`.

Экспорт: MP4, 30 или 60 кадров в секунду. «Бесшовный повтор» плавно переводит конец ролика в начало.

## Аккаунты и тарифы

Включаются, когда при сборке задан адрес сервера (`pripev.server` в `package.json`); пока он пуст, ограничений нет.

- вход по логину и паролю, кнопка «глаз» показывает пароль
- бесплатно: часть стилей и эффектов, ролики до 30 секунд, 3 видео в день, водяной знак
- Pro подключается кодом активации; без интернета оплаченный Pro работает 7 дней
- лимиты, цена, название на водяном знаке и список платных функций меняются в панели администратора

Установка сервера: [server/README.md](server/README.md).

## Куплет — плеер

Вторая программа в этом репозитории (папка `player/`): плеер для своей музыки.

**Скачать:** [Kuplet-Setup.exe](https://github.com/gdev49df/MusicPlayer/releases/download/player/Kuplet-Setup.exe)

- музыка из выбранных папок и отдельных файлов, можно перетаскивать в окно; новые файлы появляются сами
- свой вид: «Полка», песни, пластинки, артисты и кассеты (это плейлисты); справа крутящаяся пластинка с иглой и волна песни для перемотки
- поиск (казахские буквы находятся и с русской раскладки), любимые, очередь, перемешивание и повтор
- разворот с текстом: конверт с пластинкой и крупные строки, слова загораются по ходу песни; режим «Только текст»
- тексты из файла `.lrc` рядом с песней, из тегов или из интернета; сдвиг «Раньше» / «Позже», свой текст
- обложки из тегов и папки, недостающие ищутся в интернете (отключается в настройках)
- клавиши, кнопки мультимедиа, продолжение с того же места после перезапуска

Файлы пользователя только читаются. Аккаунтов и ограничений в плеере нет.

Сборка: `npm install`, `node player/build.mjs`, затем в `player/desktop`: `npm install` и `npm start` (или `npm run dist` на Windows).
Пуш с изменениями в `player/` собирает версию `1.0.N` и кладёт её в релиз с меткой `player`; на обновления «Припева» это не влияет.

## Сборка

    npm ci
    npm run build
    cd desktop
    npm ci
    npm run dist        # desktop/dist/Pripev-Setup.exe

- тексты с таймингами: lrclib.net
