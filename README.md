# Припев

Программа для Windows: из вашей песни делает видео для TikTok с обложкой и синхронным текстом.

**Скачать:** [Pripev.exe из последнего релиза](https://github.com/gdev49df/MusicPlayer/releases/latest)

Программа не подписана, поэтому при первом запуске Windows может показать окно SmartScreen:
«Подробнее» → «Выполнить в любом случае».

## Возможности

- своя музыка: MP3, M4A, WAV, FLAC
- обложка альбома и фото артиста находятся по названию
- текст с таймингами находится сам; можно поправить, вставить свой или разметить в такт
- стиль «Панель» (16:9 и 9:16): мини-плеер, карточки, виджеты, дождь, всплывающие сообщения
- ещё три вертикальных стиля: «Плеер», «Большая обложка», «Крупный текст»
- экспорт MP4, 30 или 60 кадров в секунду

Слово в звёздочках (`*слёзы*`) остаётся выделенным цветом.
Сообщения пишутся по одному в строке: `0:08 Имя: текст`.

## Сборка

    npm ci
    npm run build
    cd desktop
    npm ci
    npm run dist        # desktop/dist/Pripev.exe

## Откуда данные

- обложки и фото артиста: iTunes Search API, Deezer API
- тексты с таймингами: lrclib.net

Для поиска нужен интернет.
