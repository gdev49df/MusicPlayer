# Сервер аккаунтов «Припева»

Cloudflare Worker с базой D1: аккаунты, дневной лимит, коды активации и панель администратора.

## Установка

1. Cloudflare → Workers & Pages → Create → Import a repository: репозиторий с этим кодом.
2. Имя воркера `pripev-api`, корневая папка (Root directory) `server`. Команду выкладки оставить `npx wrangler deploy`.
3. В настройках воркера: Variables and Secrets → добавить **Secret** `ADMIN_PASSWORD` (не короче 8 знаков).
4. Адрес воркера вписать в `package.json` в корне: `"pripev": { "server": "https://…workers.dev" }` и запушить — соберётся версия с аккаунтами.

База `pripev` уже указана в `wrangler.jsonc`. Для другой базы: создать её, заменить `database_id` и выполнить
`npx wrangler d1 execute pripev --remote --file schema.sql`.

## Панель администратора

`https://адрес-воркера/admin`

- создать коды активации на нужное число дней
- найти пользователя, добавить или снять Pro, заблокировать, задать новый пароль
- изменить лимиты, водяной знак, цену, текст и ссылку «где получить код», список платных функций

## Проверка

    npm install
    npm test        # на локальной базе
    npm run dev

## Что важно знать

Видео собирается на компьютере пользователя, поэтому сервер считает ролики и проверяет коды,
но умелый человек может изменить саму программу и обойти ограничения.

Пароль растягивается в программе (PBKDF2), на сервер он в открытом виде не уходит; в базе хранится только отпечаток с солью.
